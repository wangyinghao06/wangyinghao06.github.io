接入文档

Aivaro 与 OpenAI API 格式兼容。把客户端的 Base URL 指向本站网关、用你自己的 API Key 鉴权即可调用。下方示例中的 sk-xxxxxxxx 是占位符，请替换为你在控制台创建的真实 Key（不要把真实 Key 写进公开代码仓库）。

测试阶段提示 公开注册尚未开放，API Key 由管理员向测试用户发放；已有测试账号的用户登录控制台后即可自助创建与撤销 Key。

请求示例

curl

curl https://3000-agqyuuzd3ejtzmhsnnby2wcjxm.instabox.tech/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "cohere/north-mini-code:free",
    "messages": [
      {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
  }'

Python（OpenAI SDK）

from openai import OpenAI

client = OpenAI(
    base_url="https://3000-agqyuuzd3ejtzmhsnnby2wcjxm.instabox.tech/v1",
    api_key="sk-xxxxxxxx",  # 替换为你的 Key
)

resp = client.chat.completions.create(
    model="cohere/north-mini-code:free",
    messages=[{"role": "user", "content": "你好，请用一句话介绍你自己"}],
)
print(resp.choices[0].message.content)

Node.js（OpenAI SDK）

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://3000-agqyuuzd3ejtzmhsnnby2wcjxm.instabox.tech/v1",
  apiKey: "sk-xxxxxxxx", // 替换为你的 Key
});

const resp = await client.chat.completions.create({
  model: "cohere/north-mini-code:free",
  messages: [{ role: "user", content: "你好，请用一句话介绍你自己" }],
});
console.log(resp.choices[0].message.content);

主要参数

参数类型必填说明
modelstring是模型 ID，须与模型页公布的 ID 完全一致，如 cohere/north-mini-code:free。
messagesarray是对话消息数组，每项含 role（system / user / assistant）与 content。
temperaturenumber否采样温度 0–2；值越高输出越发散。不填时由上游默认值决定。
max_tokensinteger否单次回复的最大输出 Token 数；过小可能导致回复被截断。
streamboolean否是否以流式（SSE）方式返回，默认 false。

成功响应与 OpenAI 格式一致，包含 choices（回复内容）与 usage（本次输入 / 输出 Token 用量，可用于核对额度记录）。

常见错误与排查

状态码含义常见原因排查步骤
401密钥无效 未带 Authorization 头、Key 拼写错误、Key 已被撤销或禁用。 确认请求头为 Authorization: Bearer 你的Key；到控制台核对 Key 状态，必要时新建一个 Key 重试。
403额度不足 账户总额度或该 Key 的额度上限已耗尽，或 Key 被限制了可用模型。 在控制台查看剩余额度与 Key 的模型限制；测试阶段额度有限，耗尽后联系管理员（见联系我们）。
404模型不存在 model 参数拼写错误，或模型未在本站启用。 对照模型页的模型 ID 原样复制；注意测试模型 ID 末尾的 :free 不可省略。
429请求过于频繁 触发网关限流，或上游免费测试池的每日 / 每分钟限额已用完（测试用户共享）。 降低并发与频率，间隔数十秒后重试；若持续出现，查看服务状态页公告。
500上游异常 上游模型服务故障、超时，或网关与上游连接中断。此类失败不扣减额度。 稍后重试；若多次失败，先看服务状态页确认网关状态，再经联系我们反馈请求时间与模型名。

用量与核对

每次调用都会记录时间、模型、状态与 Token 用量。登录控制台可以查看剩余额度与使用明细；若响应中的 usage 与控制台记录不一致，请记下请求时间后联系我们核对。我们记录哪些数据，见隐私政策（草案）。
