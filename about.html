关于 Aivaro 与收录规范

这一页按五个部分说明本站：它是什么、数据从哪来、名单怎么形成、发现错误怎么纠正、以及我们对使用者的声明。方法公开，结论才可核对。

一、站点说明

Aivaro 是一个独立维护的 AI API 服务导航站，做三件事：发现（把分散的官方平台、中转与聚合服务整理成一份可检索的名单）、比较（把同一模型的公示单价放到同一口径下对照）、导航（把你送到服务商官网，交易与使用都在那边发生）。

本站收录并核实公开服务信息，提供检索与导航，不收集任何第三方账号凭据。本站页面包括：首页、服务目录、服务详情、价格对比、免费额度专题、投稿收录、广告合作与本页；没有账号体系，不需要注册登录。本站与被收录的任何服务商都没有运营、代理或隶属关系。

二、数据来源

信息来源政策

  • 本站数据全部由维护者从服务商官方页面逐条查阅整理。来源优先级：①官网定价页 / 模型页；②官方文档；③官方公告（博客、状态页、官方社群公告）。三者之外一律不作为数据来源；
  • 其他导航站、店铺页、社群帖子与口头信息，最多只能作为「待核实线索」，不会被写成事实；本站也不从任何同行站点搬运数据；
  • 每条价格、额度与状态信息都在详情页给出源链接与核实日期；查不到的字段直接标「待核实」，不推测、不拿别家数据填充。

核实节奏与过期规则

  • 价格与免费额度：每 30 天逐条复核；服务状态：每 14 天快速巡检；新收录的服务在第 7 天做一次早期复核；
  • 超过应核实日期未复核的条目自动标「待复核」；超期两倍标「可能过期」，并在目录与比价排序中降权；
  • 免费额度政策若经复核确认已取消，条目标记「已失效」但保留展示——本站统计只说「最近一次复核未发现取消」，不说「可用」，因为我们无法替服务商承诺政策存续；
  • 每次核实都记入详情页的「核实记录」时间线，字段变更留痕。

分类计数口径（免费 / 低价 / 标注折扣）

  • 免费 AI API：计数取自条目的免费额度字段——核实结论为「有」的才计入。依据是两类事实：官网写明的免费额度，或其官网公开定价接口中经逐条验真的零价模型——验真须按每条记录自身的计费方式核对（按量计费看倍率是否为零、按次计费看单价是否为零），且零价模型中须包含文本对话模型；仅凭某个价格字段为零、或模型名带「免费」字样、而实际按次或按量收费的，不算免费。2026-11-04 本站按此标准复核了全部接口批条目：51 家中 50 家不能证明免费额度，已改列「待核实」，逐家结论留有审计记录备查。免费政策经复核已结束的条目按「无」记录，不计入。在此之上，每条免费信息按已核实内容再分三型并在卡片上标注：长期免费（免费权益以量或价计量且持续有效——免费模型单价为零、可持续调用，或长期有效的免费套餐与额度；不按次计数、也不是一次性发放）、注册赠送（与注册动作绑定的一次性赠额或赠金，领完即止）、限次（以次数计量的免费额度——每日、每月或总计若干次，哪怕每日刷新也归此类；例如有服务商的免费模型以每日 50 次封顶，即按限次计）。一家兼有多种构成时同时标注多型；首页分类卡按三型分别计数，同一家可重复计入多个小类，免费大类家数按条目去重。
  • 低价 AI API：只计入「低于官方价可核实」的服务：条目至少有一条已核实单价，输入与输出价均低于该模型官方价，且对比所用的官方价来自本站核实存档中以官方价为锚的比价记录。单价与官方价持平（原价口径）、高于官方价、或只有无从与官方价对照的模型单价（如存档中仅有量级区间、无官方定价）的，都不计入这一类——有价格记录不等于低价。价格低于官方不代表来源合规或服务稳定，请自行评估。本站低价锚点仅限 Claude Sonnet 官方价（Sonnet 5.5 与 Sonnet 4.6），没有该模型的服务不在低价口径内。在此之上，低价条目按其 Sonnet 价格相对官方价的比例分层呈现：70%–100% 为「略低」、30%–70% 为「明显低」、低于 30% 为「异常低价」；异常低价在卡片与详情页带风险提示、不作为推荐、不参与比价页的最低价高亮。同一家 Sonnet 5.5 与 4.6 的相对官方价比例相差一倍以上者，标记「价格不一致」，人工复核前不计入低价；仅比官方价低约 5% 的亦不计入低价，只按「略低」分层呈现其价格行。异常低价警示的触发与是否计入低价无关：任一 Sonnet 锚点模型相对官方价的比例低于 30%，即在卡片与详情页显示异常低价警示——包括因「价格不一致」被暂停低价归类的服务（价格不一致只决定是否计入低价，不影响警示）。入选低价的价格还须是默认（default）分组价格：按非默认分组合算得出的价格标为「分组价」，不计入低价。站内标价，实际成本取决于充值汇率与分组。
  • 标注折扣：与「低价」分开的一类：折扣证据只有服务商自己在官方页面并列标出的原价与折扣价，未经官方价锚点核实。这类条目在卡片上以「标注折扣」角标明示证据来源，不归入低价计数；后续复核若补上官方价对照，按结论再调整分类。
  • 首页与目录页的分类家数都由上述字段在页面加载时自动统计，不写死数字，数据增删或复核结论变化后随之更新。

状态与排序的口径

本站状态（如「官网可打开」）来自核实日的人工访问结论，不是可用性百分比，也不代表 API 网关实时可用、模型真实或计费准确。部分同行会做无凭证自动探测并披露样本量，那是他们的方法；在我们拥有持续探测样本之前，不发布此类数字。

  • 目录默认「综合」排序分三步：先把状态异常的条目整体放到最后；其余先比核实完整度（核心字段里核实到的项数），再比谁的支付方式更多、谁覆盖的模型厂商更广；仍相同的，按名称先后。本站暂无可靠的运营时长数据，故以核实完整度代偿该维度，代偿规则在此公开，不做隐藏加权；
  • 可切换的价格、最近核实、名称排序为本站附加功能；比价页默认按所选价格列升序、最低价高亮，未公示该列价格者排表尾。

三、名单来源释义

  • 名单怎么形成：候选服务来自维护者对公开渠道的持续观察与官网逐个查访；进入名单的唯一门槛是下面的收录标准，不存在付费入选；
  • 收录标准：有可访问官网、公开价格或明确免费规则；官网主体与联系方式可辨识。同类导航站也可收录，但会单独标明类型，不与卖 API 的服务混同；
  • 不收录：成品号、接码、账号租赁、反代、逆向、订阅转 API 等账号类商品——这类交易的风险无法靠信息核实消除，不在本站范围内；
  • 分类释义：「运营类型」（官方平台 / 中转 / 聚合 / 导航站）按服务商在官网的自我定位归类；「模型家族」（Claude / GPT / Gemini / DeepSeek / Grok / 国产模型 / 其他）按其已核实的厂商名单归组。两者都是本站的编辑分类，不是服务商的官方定性；
  • 收录 ≠ 推荐：出现在名单里只表示「官网可核实地存在并符合收录标准」。带「推荐」标记的是编辑基于公开信息的主观选择，逐条附理由；带「商业合作」标记的按第五部分规则单独呈现（目前无在投条目）；
  • 价格口径：单价统一为「每 1M tokens 的输入 / 输出 / 缓存读价」，保留原始币种；不同币种不自动换算混排，避免汇率口径污染比价结论。

官方平台收录标准

「官方平台」指模型厂商自营的 API 开放平台（如各大模型厂商的官方 API 服务）。这类条目与中转、聚合适用同一套核实规程，另有以下专属口径：

  • 分类按厂商官网的自我定位归类为「官方平台」，不与中转、聚合混同；
  • 只收录有公开定价页、价格可逐项核实的官方 API 平台；查不到的价格字段标「待核实」，不采用第三方口径；
  • 海外平台按其官方文档如实标注支持地区；本站只做信息导航，不提供注册或使用教程，也不提供任何绕开地区限制的方法；
  • 官方平台条目默认不带「编辑精选 / 推荐」标记，例外须有公开理由并在此页留痕；
  • 官方平台公示价同时是本站比价的官方价基准：异常低价的判定以官方价为锚，不采用任何中转服务商的价格作锚。

编辑精选（「推荐」标记）评选标准

首页「编辑精选」与卡片上的「推荐」标记，是本站编辑基于公开核实信息作出的主观评选，不是付费排名。入选主要看四点：

  • 信息透明度：官网主体、价格与使用规则公开可查，不用暗价与隐藏收费；
  • 价格可核实性：核心模型的单价能在官网公开页面逐项复核，计价口径清楚；
  • 免费额度真实性：免费额度或免费模型确为现行政策，并能在官方页面证实；
  • 官网信息完整度：模型、支付、注册与状态等关键信息齐全，有持续维护的痕迹。

编辑评选不收费、不售卖、不接受付费入选，每条入选的理由都写在卡片「推荐」标记的悬停说明里，接受公开检验。它与付费广告位是两套完全分开的机制：广告位在目录首排独立分区、带「广告」角标（见第五部分与广告合作页），投放广告不会获得「推荐」标记，也不会改变编辑评选结果。

四、纠错通道

发现条目有误、价格已变、免费政策调整，或你是被收录方想申请修正 / 下架，请通过页末的联系邮箱告知我们，并尽量附上服务商官方页面链接。我们会按与新收录相同的标准复核：确认属实的更正会更新条目并记入其「核实记录」时间线；无法在官方页面确认的，按「待核实」处理并回复说明。
