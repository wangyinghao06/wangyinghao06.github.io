一次调用是怎样计费的

  1. 1

    发送

    你在工作台发出一条消息，系统先按预估上限预留一笔额度——预留不是扣费。

  2. 2

    路由

    网关按你的分组选择可用渠道，把请求送到你选的模型。

  3. 3

    模型处理

    上游完成生成并返回实际用量（输入与输出 Token 数）。请求失败、超时或被上游拒绝，不计费。

  4. 4

    结算回执

    按下方公式结算，预留多出的部分退回；每一笔用量都能在控制台记录中核对。

额度消耗 ＝（输入 Token ＋ 输出 Token × 输出倍率）× 模型倍率 × 分组倍率

例：一次短对话输入 30、输出 500，取模型倍率 1、输出倍率 1、分组倍率 1 →（30 ＋ 500×1）× 1 × 1 ＝ 530 额度。各模型的倍率与换算结果见上方卡片，可自行复算。

开放范围与商用说明

受控试运行，未公开商用 Aivaro 工作台目前为受控试运行：不开放公开注册、不接受充值、不售卖任何套餐，账号由管理员开通。DeepSeek 模型已作为工作台内的可用模型接入，按平台额度计量；这不等同于公开商业运营，裸 API 转售不在开放范围内。进展会同步更新到本页与服务状态页的公告中。

计量方式

  • 按 Token 计量

    每次请求按上游返回的实际用量（输入 + 输出 Token）记录；上游未提供用量时，按网关的可核对规则记录并在日志中标注。

  • 失败不计费

    请求失败、超时或被上游拒绝时不扣减额度；已预扣的会在结算时退回，可在控制台用量记录中核对。

  • 额度上限

    用户总额度与单个 Key 的额度上限相互独立，任一耗尽都会返回 403。测试阶段额度由管理员发放与调整。
