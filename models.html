关于「测试标定」：网关内部按 1:1 的标定比例记录该模型的用量，用于验证计量与额度扣减逻辑是否正确。这不是正式商用价格，也不产生真实费用。测试模型来自上游免费池，所有测试用户共享其每日限额（当前为每日 50 次量级），高峰时可能返回限流错误（429），属正常现象。

正式商用模型与费率

尚未开放 正式商用模型与费率将在合规上游确认后公布：即上游服务条款明确允许商业使用、并允许通过自建 API 网关向客户提供模型服务之后。在此之前，本站不售卖任何套餐、不接受充值，也不会把免费测试额度包装成商业服务。进展会同步更新到本页与服务状态页的公告中。

计量方式

按 Token 计量

每次请求按上游返回的实际用量（输入 + 输出 Token）记录；上游未提供用量时，按网关的可核对规则记录并在日志中标注。

失败不计费

请求失败、超时或被上游拒绝时不扣减额度；已预扣的会在结算时退回，可在控制台用量记录中核对。

额度上限

用户总额度与单个 Key 的额度上限相互独立，任一耗尽都会返回 403。测试阶段额度由管理员发放与调整。
