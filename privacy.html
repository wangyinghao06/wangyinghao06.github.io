隐私政策（草案）

最近更新：2026-11-01 · 本页为草案，正式版本将在服务正式开放时发布并以正式版本为准。

草案提示：本政策目前为草案，用于如实说明测试阶段的数据处理方式。正式商用前我们会发布正式版本。

1. 我们记录什么

为提供网关转发、计量与排障，本服务会记录以下数据：

  • 账户信息：用户名、账户状态，以及以不可逆散列方式存储的密码（我们无法看到你的明文密码）。
  • API Key 信息：Key 的归属用户、创建时间、状态与额度设置。完整 Key 仅在创建时向你展示一次。
  • 请求元数据：每次调用的时间、使用的模型、HTTP 状态、耗时与来源 IP，用于计量、限流与故障排查。
  • 用量数据：每次请求的输入 / 输出 Token 用量与额度扣减记录，你可以在控制台查看并核对。

2. 请求内容如何处理

你发送的提示词与模型回复会被转发给上游模型提供商处理，其处理方式受上游各自的隐私政策约束。本站自身不把你的对话内容用于模型训练，也不出售任何用户数据。排障日志以元数据为主；如需定位具体故障，我们可能在必要范围内查看相关请求记录，并会控制访问权限。

3. 在线体验（对话演示）不保存什么

本站的「在线体验」演示不设账号、不保存聊天记录：对话只保存在你当前页面内，刷新即清空；其服务端日志不记录对话内容。该演示与 API 网关共用同一上游免费测试池，请勿在演示中输入任何敏感或个人信息。

4. 数据的共享

  • 除转发给上游模型提供商以完成你的请求外，我们不向第三方提供你的数据。
  • 我们不出售、不出租用户数据，也不将其用于广告投放。
  • 本站页面不嵌入任何第三方统计、广告或追踪脚本。

5. 数据保留与删除

测试阶段的用量与日志数据会保留至测试结束或账户注销时。如需查询、更正或删除与你账户相关的数据（包括注销测试账号），请通过联系我们页面所列的 GitHub Issues 渠道提交请求并注明用户名；我们会在核对身份后处理，并通过同一渠道回复结果。

6. 安全措施

网关与上游之间的凭证只保存在服务端，不出现在任何页面、前端代码或日志中。尽管如此，互联网传输无法保证绝对安全，请勿通过本服务发送高度敏感的信息。

7. 政策变更

本政策可能随测试进展修订，修订后在本页公布即生效。重大变更会同时更新服务状态页公告。
