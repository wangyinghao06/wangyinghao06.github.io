产品介绍

小屿 API 是一个轻量的 AI API 网关。客户端按 OpenAI 兼容格式发送请求，网关负责校验你的 API Key、按模型路由到上游、计量 Token 用量并扣减额度，全过程返回标准的状态码与错误信息，方便接入与排障。

OpenAI 兼容接口

请求与响应格式与 OpenAI API 保持一致，现有 SDK 和客户端只需修改 Base URL 与 Key 即可接入。

统一额度与用量

每个用户、每个 API Key 独立计量。控制台可查看剩余额度、调用次数与 Token 使用记录，便于核对。

Key 自主管理

在控制台自行创建、撤销 API Key，可为不同用途设置独立 Key 与额度上限，降低泄露风险。

规范的错误返回

鉴权失败、额度不足、模型不存在、限流与上游异常都有明确的状态码与说明，排查路径见接入文档。
