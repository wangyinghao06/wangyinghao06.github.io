前往 GitHub Issues

反馈时请带上这些信息

请求问题

发生时间（精确到分钟）、使用的模型 ID、返回的状态码与错误信息原文。不要贴出完整的 API Key。

用量问题

你的用户名、存疑记录的时间与模型，以及控制台显示的扣减数值，方便逐项核对。

数据请求

查询、更正或删除账户数据时，请注明用户名与请求类型；涉及身份核对时我们会通过 Issue 与你确认。

关于响应速度 测试阶段的支持为尽力而为（best-effort）：由维护者业余时间处理，不承诺响应时限，也没有电话或即时通讯支持。紧急的可用性问题请先查看服务状态页——测试环境托管于免费平台，闲置暂停后的唤醒延迟通常会在数分钟内自行恢复。
